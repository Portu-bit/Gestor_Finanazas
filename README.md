# Gestor de Finanzas Personales
Una aplicación de línea de comandos que permite:

Registrar ingresos y gastos, entre otras cosas (se detalla mejor en las funcionalidades)

## Tecnologías
Python

## Instalación
```bash
git clone https://github.com/Portu-bit/Gestor_Finanazas.git
cd Gestor_Finanazas
pip install pytest
python main.py
```
## Funcionalidades
Registrar ingresos y gastos
Consultar el balance actual
Ver historial de transacciones
Exportar reporte en CSV
Guardar todo en SQLite
